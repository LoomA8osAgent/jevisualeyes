# Fixture provenance

Everything in this directory is **synthetic/hand-authored test material**, except a future explicitly saved live receipt produced by an operator outside this handoff. The example MIDI is the performed (shuffle-timed) export of `hand-authored-project.json`, not a model-generated song. The example API response probabilities and usage values are fabricated test values, not measurements.

`jev-request.json` is a valid-shaped example request with a complete enumerated event palette. `jev-response.synthetic.json` and `decision-receipt.synthetic.json` test response/trace parsing only. `edit-request.json` demonstrates a bounded edit; it has not been executed by a production app.
